# Análisis de Clientes de Centros Comerciales

## Descripción

Proyecto de análisis de datos enfocado en el estudio del comportamiento y las características de clientes de centros comerciales.

El proyecto busca explorar los datos, identificar patrones y generar información útil mediante técnicas de análisis y visualización de datos.

## Objetivos

- Explorar y comprender el conjunto de datos.
- Realizar limpieza y preparación de los datos.
- Analizar las principales características de los clientes.
- Identificar patrones y comportamientos relevantes.
- Generar visualizaciones para facilitar la interpretación de los resultados.
- Obtener conclusiones a partir del análisis realizado.

## Tecnologías utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
